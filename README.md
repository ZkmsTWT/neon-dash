# NEON DASH · 矢量跑酷

> 纯 HTML5 Canvas 实现的类矢量跑酷（lane-runner）游戏 · 零依赖 · 打开即玩

## 🎮 在线即玩

无需克隆、无需构建 —— 直接点下面链接，浏览器里就能玩（GitHub Pages 版）：

👉 **<a href="https://ZkmsTWT.github.io/neon-dash/"><b>ZkmsTWT.github.io/neon-dash</b></a>**

## 本地运行

```bash
# 方式 1：直接打开
open index.html            # macOS
xdg-open index.html        # Linux

# 方式 2：本地静态服务器（推荐，localStorage 表现最稳）
npx serve .
# 或
python3 -m http.server 8000
```

然后访问 http://localhost:8000 （或 8080）。

## 玩法

| 按键 | 功能 |
| --- | --- |
| `←` / `→` | 切换三条车道 |
| `空格` / `↑` | 跳跃（跳过低栏，躲开高栏） |
| `Shift` | 加速冲刺（消耗能量条） |
| `Enter` | 开始 / 重新开始 |

触屏设备会自动显示虚拟按键。

## 障碍类型

| 类型 | 颜色 | 应对 |
| --- | --- | --- |
| 低栏 | 🔴 红 | 跳跃越过 |
| 高栏 | 🟡 黄 | 保持落地，**不要跳** |
| 能量墙 | 🟣 紫 | 换车道避开 |
| Slalom 双门 | 🟣 紫 | 只有一条开口车道，走对就能过 |

## 得分系统

- **基础分**：随奔跑距离持续增长，速度越快分涨越快
- **宝石**：每颗 +15 基础分，连吃触发连击
- **连击**：2 颗起 `COMBO x2`，最高 ×10（断连即清零）
- **冲刺**：速度 ×1.55、得分 ×1.6，能量条耗尽后需等待回复
- **最高分**：本地 `localStorage` 自动保存

## 技术要点

- **伪 3D 透视**：单文件 Canvas，世界坐标 → 屏幕坐标投影（`f/z` 缩放 + 地平线偏移）
- **渲染排序**：所有可绘制物按 z 深度排序后绘制，保证遮挡正确
- **粒子系统**：跳跃/落地环波、收集火花、冲刺拖尾，三种粒子类型
- **色调漂移**：`hue` 随 `dist` 渐变，霓虹感随跑动流动
- **难度曲线**：速度上限 `16 + dist × 0.012`，障碍生成间隔随距离缩短
- **防死局**：双墙叠加时避开 Slalom 开口车道，保证每段必有可通过路线
