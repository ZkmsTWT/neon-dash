> 纯 HTML5 Canvas 类矢量跑酷（lane-runner）· 零依赖 · 双机位 · 打开即玩

## 本地运行

```bash
open index.html          # 直接打开
npx serve .             # 或本地静态服务器（localStorage 最稳）
python3 -m http.server 8000
```

## 玩法

| 按键 | 功能 |
| --- | --- |
| `←` / `→` | 切换三条车道 |
| `空格` / `↑` | 跳跃（跳过低栏，躲开高栏） |
| `Shift` | 加速冲刺（消耗能量条） |
| `Enter` | 开始 / 重新开始 |
| **`C`** | **切换第三人称 / 第一人称视角** |
| `1` / `2` | 直接指定 3P / 1P |

触屏设备自动显示虚拟按键（含 📷 视角切换）。

## 双机位系统（v2 核心特性）

| 机位 | 特点 | 按键 |
| --- | --- | --- |
| **第三人称** | 相机在玩家身后 3.4u、高 2.1u，带**位置 + 视角双重惯性阻尼**（`exp` 帧率无关），跑动/换道有电影感甩尾；撞墙有镜头震动 | `C` / `1` |
| **第一人称** | 相机固定在**胸口 1.55u 高**，跑步时有上下起伏（bob）+ **左右摆臂**（双臂从画面下角伸出，前摆时手抬高放大、后摆时降低缩小）；画面下方有胸前 HUD 准心 | `C` / `2` |

两种机位共用同一套世界坐标渲染管线，切换瞬间无缝过渡。

## 具象化场景（v2 视觉）

路旁不再是抽象光柱，而是 5 种具象化霓虹城市物件（按深度排序、随距离滚动）：

| 物件 | 外观 |
| --- | --- |
| **霓虹塔楼** | 长方体 + 随机点亮窗户 + 顶部霓虹边 + 天线 |
| **拱门** | 双立柱 + 横梁 + 横向发光条 |
| **能量柱** | 锥体 + 顶部光球 |
| **全息广告屏** | 立柱 + 发光面板 + 闪烁内容块 |
| **路灯** | L 形杆 + 灯头 + 地面光晕 |

天空与地面**对比度拉高**：深蓝夜空 → 品红地平线（高饱和）；地面为深紫黑沥青 + 霓虹路缘发光边。

## 得分系统

- **基础分**：随奔跑距离持续增长，速度越快分涨越快
- **宝石**：每颗 +15 基础分，连吃触发连击
- **连击**：2 颗起 `COMBO x2`，最高 ×10（断连即清零）
- **冲刺**：速度 ×1.55、得分 ×1.6，能量条耗尽后需等待回复
- **最高分**：本地 `localStorage` 自动保存

## 技术要点

- **双机位投影管线**：世界坐标 → 屏幕坐标，相机 z 随模式变化（3P 在玩家后 3.4u，1P 在胸口），`relZ = wz - camZ` 统一处理
- **惯性相机**：位置/视角分别用 `1 - exp(-k·dt)` 帧率无关阻尼，跑动有甩尾感
- **第一人称摆臂**：`sin(runPhase)` 驱动左右手前后摆，手随前摆抬高放大、后摆降低缩小（模拟透视）
- **深度排序**：所有可绘制物（障碍/宝石/场景）按 z 排序后绘制，遮挡正确
- **粒子系统**：跳跃/落地环波、收集火花、冲刺拖尾
- **色调漂移**：`hue` 随 `dist` 渐变
- **难度曲线**：速度上限 `16 + dist × 0.012`
- **防死局**：双墙叠加时避开 Slalom 开口车道
