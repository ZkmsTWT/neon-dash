# NEON DASH · 矢量跑酷

一个纯 HTML5 Canvas 实现的类矢量跑酷（lane-runner）游戏，零依赖、单页即玩。

## 玩法
- **← / →** 切换三条车道
- **空格 / ↑** 跳跃（跳过低栏，躲开高栏）
- **Shift** 加速冲刺（消耗能量条，可收集宝石更快刷分）
- **Enter** 开始 / 重新开始

## 障碍类型
| 类型 | 应对 |
| --- | --- |
| 红色低栏 | 跳跃越过 |
| 黄色高栏 | 保持落地，不要跳 |
| 紫色能量墙 | 换车道避开 |
| 双门 Slalom | 从唯一开口车道通过 |

## 特色
- 霓虹网格 + 伪 3D 透视，场景色调随距离渐变
- 连击系统：连续吃宝石最高 ×10 倍分
- 加速冲刺：速度 ×1.55、得分 ×1.6，但能量耗尽需要等回复
- 本地最高分记录（localStorage）
- 触屏设备自动显示虚拟按键

## 运行
直接用浏览器打开 `index.html` 即可，无需服务器。

也可以本地起个静态服务：
```bash
npx serve .
```
